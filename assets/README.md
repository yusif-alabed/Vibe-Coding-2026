# Assets

The current art is generated in code (see `docs/art-style.md` and `client/src/game/`), so this folder is empty for now.

Put future original assets here:

- `sounds/` — footsteps, splash, sled swoosh, coin chime, cozy background music (must be original or properly licensed)
- `models/` — any hand-made low-poly models (keep them flat-coloured to match the style)
- `textures/` — only if needed; flat, hand-painted looks only
